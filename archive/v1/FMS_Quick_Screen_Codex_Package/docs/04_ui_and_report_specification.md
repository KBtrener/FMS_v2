# Interfejs i raport

Zachowaj istniejący system wizualny: kafelki, typografię, odstępy, kolory, stany i responsywność.

## Wizard

Najpierw pokazuj test nadrzędny i rzeczywisty wynik. Następnie clearing z etykietą Test clearing oraz informacją Powiązany z. Shoulder Clearing grupuj stronami: dla jednej strony wzorzec górny (ból, zakres), wzorzec dolny (ból, zakres), potem druga strona. Shoulder Mobility pozostaje bez zmiany przebiegu.

## Profil i raport

Pokazuj L/R, asymetrię, wynik bazowy, wyniki clearingów, wynik końcowy oraz nazwę clearingu, który wywołał zmianę. Raport grupuje clearingi pod testami nadrzędnymi. Przy zmianie pokazuje np. Neck Extension Clearing — ból oraz baza 2 → final 0.

Panel administratora pozwala tworzyć, aktywować, dezaktywować i przeglądać reguły. Przycisk Wstecz przeglądarki ma wracać do poprzedniego widoku/kroku również na desktopie.
