# QuickScreen V2 — aktualne źródła dla redesignu

> Ta paczka jest kopią pomocniczą i może nie zawierać ostatnich zmian. Używaj nadrzędnego `../../README.md`, `../QuickScreen-V2-AKTUALNY-KOD.md` oraz `../../docs/ASSESSMENT_FLOW_V2.md` jako aktualnych instrukcji i źródeł.

Ta paczka zawiera źródła aktualnej makiety, żeby można było przejrzeć wszystkie ekrany, pytania, dane demonstracyjne i flow.

- `index.html` — punkt wejścia i kolejność ładowania modułów.
- `js/` — ekrany, pytania i nazwy testów, dane demonstracyjne, nawigacja oraz logika interakcji.
- `css/` — aktualny system wizualny i style ekranów.
- `assets/` — logo, fonty i grafiki.
- `brief/` — trzy wymagane pliki z wytycznymi redesignu.

Źródłem prawdy dla istniejących tekstów i zachowania jest kod w tej paczce. Zachowaj wszystkie teksty znak w znak i nie zmieniaj obecnego flow wizarda.

Aby obejrzeć aplikację, uruchom ją przez serwer statyczny pod ścieżką `/quick-screen-v2/` (tak jak w obecnym wdrożeniu). Makieta działa bez logowania i backendu.
