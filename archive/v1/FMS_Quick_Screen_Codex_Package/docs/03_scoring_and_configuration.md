# Punktacja i konfiguracja Quick Screen

Wynik ruchowy wynosi 0–3 zgodnie z manualem. Test clearing nie ma wyniku 0–3; rejestruje ból/bez bólu lub odpowiedź z konfiguracji.

## Kolejność i hierarchia

1. Cervical Flexion
2. Cervical Rotation
   - Neck Extension Clearing
3. Toe Touch
4. Shoulder Mobility
   - Shoulder Clearing
5. Rotation
6. Balance
7. Squat
   - Spine Extension Clearing

Neck Extension Clearing jest osobnym testem pod Cervical Rotation. Ból przy wyproście nie jest polem formularza rotacji.

Dla testów obustronnych zapisuj L/R. Wynik bazowy jest niższym wynikiem strony. Clearing może ustawić final na 0, ale nie zmienia bazy.

Przykład: Shoulder Mobility L=2, R=1, baza=1; Shoulder Clearing Right=ból; final=0; raport pokazuje L=2, R=1, asymetrię, bazę i przyczynę.

Panel administratora konfiguruje źródło, wyzwalacz, cel, efekt, wartość i przyczynę reguły. Total Screen Score sumuje wyniki końcowe.
